# Referência de Formulários — Fase 2

Este diretório documenta, para cada módulo **publicado** da Fase 2 (Agentic AI & Orquestração), os campos conceituais que os três Google Forms do módulo (`baseline`, `evidence`, `reflection`) devem ter.

Assim como em [docs/forms/foundations/](../foundations/README.md), isto **não** é a configuração de runtime da aplicação — é o roteiro de conteúdo para quem for criar os Forms no Google Forms. A forma de conectar os Forms à aplicação é a mesma da Fase 1 (ver o README de `docs/forms/foundations/` e a documentação de formulários do projeto); enquanto um Form não estiver configurado, a seção correspondente do módulo mostra o estado "configuração pendente" e a página continua funcional.

## Estrutura comum aos três Forms

A mesma da Fase 1, alinhada a [docs/learning-model.md](../../learning-model.md):

- **baseline** — antes do conteúdo; captura percepção inicial.
- **evidence** — após o lab; registra a aplicação prática.
- **reflection** — ao final; captura mudança de percepção e intenção de aplicação real.

Campos que se repetem: `participant_id` (oculto/prefill, nunca pedido manualmente), `role` (apenas no baseline), escalas 1–5 com o mesmo texto da Fase 1 (1 = "Nunca ouvi falar" … 5 = "Consigo explicar e aplicar com segurança") e "Consegue aplicar" (`não` / `com ajuda` / `sim`).
